## 📌 Project Overview

This project is based on **MOHA (Ministry/Management System Project)** where I performed **Manual Testing and API Testing using Postman**.

The main objective was to ensure system functionality, reliability, and correctness by validating different modules and API endpoints.

---

## 🧪 Types of Testing Performed

- ✔️ Manual Testing  
- ✔️ API Testing (Postman)  
- ✔️ Functional Testing  
- ✔️ Regression Testing  
- ✔️ Positive & Negative Testing
